🎯 O que é SDPREJ?

SDPREJ é um dashboard automatizado que coleta, analisa e apresenta dados de prejuízos da Trend Operadora em tempo real.

Objetivo: Fornecer visibilidade centralizada para gerentes e diretoria sobre:

  • 📊 Distribuição de prejuízos por tema, fornecedor e departamento
  • 👤 Desempenho de analistas e fila de análise
  • 🔗 Rastreamento de incidentes vinculados a GDIS
  • 🔴 Alertas para chamados em risco (180+ dias)

🚀 Como Usar

Acesso ao Dashboard

  1. Abra o Confluence
  2. Navegue para "DASHBOARD - SDPREJ TREND"
  3. Clique no botão azul "ABRIR PAINEL INTERATIVO"
  4. O painel abre em nova aba com gráficos e filtros

Navegação no Painel

📋 VISÃO 1: TEMAS

  • Tema: Classificação por padrão derivado (Reserva Orfa, Reacomodação, Fraude, etc)
  • Problema: Natureza da falha (operacional, técnica, etc)
  • Fornecedor: Qual fornecedor/hotel está envolvido
  • Aging: Dias em aberto (0-90d, 91-180d, 181-365d, etc)
  • Mensal: Evolução de valor reclamado mês a mês

Filtros: Por tema, faixa de dias, departamento responsável

👤 VISÃO 2: ANALISTAS

  • Timeline: Ciclos concluídos por mês (produtividade)
  • Ritmo: Ciclos por analista (quem mais conclui análises)
  • Fila: Chamados aguardando supervisão por faixa de dias

Crítico: Chamados 181+ dias em fila = risco de prescrição

🔗 VISÃO 3: GDIS

  • Situação: Status do incidente no GDIS (resolvido, em análise, pendente)
  • Etapa: Qual etapa do SDPREJ o chamado está
  • Escalação: Nível N1/N2/N3

Insight: Um GDIS pode gerar múltiplos chamados — resolver um fecha vários

⚙️ Arquitetura e Funcionamento

Pipeline de Atualização (Automático Diariamente)

1. EXTRAÇÃO (Jira)
   └─ Coleta 1.513 chamados do Jira
   └─ Extrai: status, tema, valor, departamento, etc
   └─ Gera: data/temas.json, data/analistas.json, data/gdis.json

2. BUILD (Compilação)
   └─ Combina: CSS + JavaScript + dados JSON
   └─ Gera: dist/SDPREJ_Painel.html (autocontido, offline)

3. CONFLUENCE (Publicação)
   └─ Gera tabelas + KPIs formatados
   └─ Atualiza: página index com dados tabulares
   └─ Resultado: Dashboard visual + Painel interativo

4. AGENDADOR (Windows Task Scheduler)
   └─ Roda: Diariamente 08:00
   └─ Automático: sem intervenção manual

Dados e Segurança

Dados Extraídos Valor de prejuízo, tema, departamento, fornecedor, data, analista
Dados Sensíveis (NÃO exportados) Email pessoal, CPF, informações de cliente final
Armazenamento Apenas em memoria durante processamento; dados finais em Confluence
Segurança de Rede Servidor local com acesso via hostname corporativo (futuro: DNS TI)

❓ FAQ — Perguntas Frequentes

P: Com que frequência os dados são atualizados?

R: Diariamente via agendador do Windows. Atualização automática: sem necessidade de ação manual.

P: Por que alguns chamados estão com 180+ dias?

R: Risco de prescrição. Prejudicial = 2 anos. Esses precisam de ação urgente.

P: O painel funciona offline?

R: Sim! O arquivo HTML é autocontido (CSS + JS + dados embutidos). Funciona sem internet depois de aberto.

P: Posso filtrar os dados?

R: Sim! Cada visão tem filtros: por tema, departamento, analista, faixa de dias, etc.

P: Como faço para compartilhar o painel com outras pessoas?

R: Envie o link do Confluence. Qualquer um com acesso consegue abrir.

P: O painel fica atualizado se eu deixar aberto a noite inteira?

R: Não. Recarregue a página (F5) pra puxar os dados mais recentes.

🛠️ Troubleshooting

Painel não carrega

  • ✓ Verifique sua conexão de rede
  • ✓ Recarregue a página (CTRL+F5)
  • ✓ Limpe o cache do navegador

Dados parecem desatualizados

  • ✓ Recarregue (F5) — o painel em cache pode ser antigo
  • ✓ Verifique a data/hora do atualizado na página do Confluence

Gráficos aparecem em branco

  • ✓ Use Chrome, Firefox ou Edge (versões recentes)
  • ✓ Desative extensões bloqueadoras (adblockers)
